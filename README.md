## What I'm building

- 🤖 [**nomad**](https://github.com/nityamittal/nomad) — a local-first coding
  agent on a fully self-hostable stack: Ollama (or any OpenAI-compatible
  server), stdlib-only Python, SQLite for vectors. No API keys required.
- 🎬 [**CineRank**](https://github.com/nityamittal/CineRank) — real-time movie
  recommendations: Kafka ingestion → stream processing → Redis feature store
  → SVD collaborative filtering → FastAPI, running as a full Docker Compose
  stack on MovieLens 32M.
- 🧠 [**MiniGPT**](https://github.com/nityamittal/MiniGPT-From-Scratch-Transformer-Language-Model-) —
  a GPT-style decoder-only transformer (RoPE, SwiGLU, RMSNorm) in PyTorch,
  pretrained on FineWeb-Edu and fine-tuned into a chatbot.
- 📚 [**Needle**](https://github.com/nityamittal/Needle-Research-Assistant) —
  a RAG research assistant on Vertex AI + Vector Search + Firestore: ask a
  question, get grounded answers from your own paper library.
- 🔒 [**PrivNLGBench**](https://github.com/nityamittal/PrivNLGBench---DP-Benchmark-Dataset) —
  a benchmark for privacy–utility trade-offs in synthetic text generation
  across Yelp / Enron / Clinton email corpora.
